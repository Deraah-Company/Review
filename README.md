# Academy — GitHub Pages demo

ارفع محتويات هذا المجلد مباشرة إلى جذر مستودع GitHub. لا ترفع ملف ZIP نفسه.

Settings → Pages → Deploy from a branch → main → / (root) → Save.

افتح رابط الموقع بعد اكتمال النشر. لا تحتاج Docker أو Render أو كمبيوتر يعمل.

الحسابات:
- الإدارة: admin@academy.local
- مدرب: sidebar.qa@academy.local
- متدرب: followup.qa@academy.local

كلمة المرور لكل الحسابات: Demo!Academy2026

هذه نسخة عرض مستقلة بواجهة الأكاديمية وقواعدها وبيانات أمثلتها. جميع البيانات الأولية متاحة ضمن ملفات العرض. التعديلات والملفات الجديدة تُحفظ في متصفحك فقط باستخدام IndexedDB. يستطيع كل زائر تجربة نسخة مستقلة؛ المحادثات والتقدم لا تتزامن بين أجهزة مختلفة. إعادة تحميل الصفحة لا تمسح التعديلات؛ مسح بيانات الموقع يعيد أمثلة البداية. المدفوعات تجريبية. لا تستخدم بيانات حقيقية في هذه النسخة.

أجزاء الفيديو الثلاثة تُجمع تلقائيًا عند تشغيله، وتحافظ على الملف الأصلي دون تغيير. ارفع جميع الملفات معًا. أكبر ملف أقل من 25 ميجابايت.

بعد تحديث الملفات، أغلق تبويبات العرض القديمة وافتح الموقع مجددًا لضمان استخدام النسخة الأخيرة.
